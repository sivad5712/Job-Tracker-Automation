# Changelog

## [1.0.0] - 2026-08-30

### Added
- Gmail recruiter/vendor sent-email detection
- Recruiter record extraction and Gmail deep links
- Portal/direct application detection
- ATS/portal identification
- Company and position extraction
- Recruiter status engine
- Portal application status engine
- Daily `YYYY-MM-DD` sheets
- Dynamic four-row spacing between tracker sections
- Hidden `_Processed` duplicate tracking
- `All Jobs` master sheet
- Historical recruiter/application/status backfills
- Backfill progress logging
- Google Sheets dashboard
- Master automation with locking
- Time-driven trigger support
